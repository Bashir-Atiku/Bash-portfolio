## Image Tips

✅ **Best Practices:**
- Use high-quality, professional photos
- Ensure good lighting and clear visibility
- Professional headshot recommended for profile
- Smile and face the camera
- Wear professional attire
- Keep neutral/light background

❌ **Avoid:**
- Blurry or low-resolution images
- Casual/unprofessional photos
- Very dark or distracting backgrounds
- Extreme cropping

## Format Guide

### Profile Photo Recommendations:
- **Size**: 300x300 pixels (square)
- **Format**: .jpg, .png, or .webp
- **File size**: 50-200 KB recommended
- **Style**: Professional headshot, smiling

### Hero Photo Recommendations:
- **Size**: 300x300 pixels (circular)
- **Format**: .jpg, .png, or .webp
- **File size**: 50-200 KB recommended
- **Style**: Welcoming, friendly, can be full-body or headshot

## If Images Won't Display

If images don't appear after adding them:

1. **Check file names** - Must be exactly:
   - `bashir-profile.jpg`
   - `bashir-hero.jpg`

2. **Check file location** - Files must be in same folder as `index.html`

3. **Check browser cache** - Clear browser cache and refresh (Ctrl+Shift+Delete)

4. **Try different format**:
   - If using .jpg doesn't work, try .png
   - Update the filename in the HTML if you change the format

5. **Alternative file names** (if you prefer):
   - Edit the HTML and change the image filenames
   - For example: change `bashir-profile.jpg` to `profile.png`
   - Must update in 3 places:
     - index.html (hero-image)
     - about.html (about-image)
     - contact.html (2 places - form and info section)

## Image Optimization Tips

For better performance:
1. Compress images (use TinyPNG.com or similar)
2. Use .webp format for smaller file sizes (requires browser support)
3. Keep file sizes under 200KB per image
4. Use descriptive alt text (already included in the code)

## Need Help?

If you're having issues with images:
1. Check file names match exactly
2. Verify files are in the portfolio folder
3. Clear browser cache
4. Try opening in a different browser
5. Check browser console for error messages (F12)
